本文章永久分享链接： https://tflow.top/image-converter

github地址： https://github.com/xryul/obsidian-image-converter

非常好用的图像格式管理工具，目前常用的功能主要包括
- **自由拖拽调整图片大小**
- **粘贴图片时自动转换为目标格式和质量**
- **自定义重命名**

本篇主要介绍其设置参数。

# convert设置

- convert to：转换成什么格式，默认WebP
- quality：调整图像质量
- resize mode：是否调整图像长宽
- skip patterns：不转换的目标格式

# output 设置

output location：默认就好
file naming：图像自动重命名为指定模式
if an output file already exists：遇到已存在图片的解决方案

剩余的设置保持默认即可
