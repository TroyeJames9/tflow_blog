

THE SPIKE BX · ULTIMATE · WINDOWS x64 · 8.1.108

**启动**  
将整个压缩包解压到一个单独的文件夹。运行 TheSpikeBX-Ultimate.exe。  
game 和 _internal 文件夹必须与程序放在同一目录下。  
不需要 Python、Android 模拟器或 iOS 设备。  
在游戏窗口中通过浏览器登录 Kuzyabx ID。Ultimate 需要账户许可证。

**菜单**  
F8 — 显示/隐藏面板。菜单可以移动和调整大小。  
角色：142 个模板，支持搜索、筛选主要角色以及变体/皮肤。  
技能：来自移动版 Ultimate 的 119 套特性组合。可以组合多套。  
原生特性会保留；相同技能不会重复添加。  
在比赛外选择技能并点击“应用更改”。  
如果比赛正在进行，更改会等待比赛结束后生效。清空选择会恢复原生特性。

**玩法**  
相机：开启、距离 0 到 20、重置。  
持续时间长的技能：活动效果最长 20 分钟；请在比赛开始前启用。  
动画重复。King Raul 和 Invincible / First Impact 场景、光环和减速。  
第三赛季规则：普通、格挡 + 瞄准、有限格挡。  
部分参数和动画会从下一场比赛开始生效。

**套装与配置文件**  
最多 100 个套装：保存、编辑、重命名、删除、复制链接。  
BXSKILLS1 链接与同一技能目录版本的 iOS 和 Android 兼容。  
面板会打开套装社区网站。  
最多 20 个本地配置文件，各自具有独立登录和游戏存档。  
新配置文件需要先点击“切换配置文件”选择，然后在游戏中登录。  
切换会关闭当前游戏并启动所选配置文件。  
设置：缩放、置顶于游戏上方、恢复窗口位置。  
API / DEV 选择仅在服务器端会话验证后对 kuzyabx 账户可用。  
它在重启后生效；其他账户始终使用 API。

**数据与诊断**  
所有游戏请求都包含 kuzyabxEdition = ultimate。  
PC 版数据存储在 %LOCALAPPDATA%\TheSpikeBXUltimate。  
logs 中包含简短的启动、请求和技能应用日志。  
请求正文、密码和令牌不会写入这些日志。  
普通 BX 版本和 Steam 版本的存档分开存放。  
要完全退出：设置 → 结束游戏并退出。  
叉号会在游戏运行时隐藏面板；可按 F8 恢复。  
源文件校验绑定版本 8.1.108。  
不要用其他版本的文件替换 game：不同版本的引擎地址不同。

**新增内容：**

1. **更方便的技能选择**  
    角色位于左侧，技能以网格形式位于右侧。现在屏幕上能容纳更多选项，不必不断翻长长的列表。按角色和技能搜索的功能保留了下来。
    
2. **更新后的套装部分**  
    套装以多列卡片形式显示。可以直接在所选套装内更改角色及其技能。  
    应用按钮上现在会显示套装名称。例如：“应用：我的阵容”，这样就能清楚你启用的是什么。
    
3. **第三赛季比赛规则**  
    在“玩法”部分新增了为其他比赛选择附加规则的选项：  
    🔹 **格挡与瞄准。** 中央拦网手获得防护圈。当进攻面对起跳的拦网手时，会出现选择击球方向的箭头，如同剧情模式中一样。  
    🔹 **有限格挡。** 按照剧情阶段的规则改变 AI 控制的拦网手的行为。  
    🔹 **普通比赛规则。** 关闭附加条件。  
    每个选项下方都有说明。所选规则对双方队伍都生效，并从下一场比赛开始应用。  
    [视频：模式“格挡+瞄准”]
    
4. **模组菜单的独立设置**  
    新增了“设置”部分，可以根据自己的屏幕更改元素大小、菜单宽度和高度。  
    将相机、长时间技能、动画重复和比赛规则集中在“玩法”部分。
    
5. **外观修复**  
    修正了 Android 上下拉列表的颜色。现在有浅色背景、可读文本和清晰的选中项高亮。
