> [!NOTE]- 新高级配置文件`config.json`的说明
> 从 Parsec 版本 150-89 开始，Parsec 会将所有高级配置从 `config.txt` 移至 `config.json`。这个新的配置文件与`config.txt`位于同一位置。 **<span style="color: #ff7575">您仍然可以将配置选项添加到 `config.txt`，Parsec 会将它们移至 `config.json`，以实现向后兼容性。</span>**
> 
> 如果你是windows，`config.json`位于以下位置：
> 
> - 安装时选择per user： `%APPDATA%\Parsec\config.json`
> - 安装时选择per computer： `C:\ProgramData\Parsec\config.json`
> 
> 如果你是macOS，`config.json`位于以下位置：
> 
> -  正常安装: `~/.parsec/`
> - [用于登录屏幕访问的自定义共享安装程序](https://parsecunity.zendesk.com/hc/en-us/articles/32381618319124-Access-Login-Screen-on-macOS)：`/Users/Shared/.parsec/`
> 
> 请记住：
> 
> - 只有在正确保存`config.txt`并重新启动 Parsec ，才会自动迁移配置到`config.json`。保存并迁移设置后，**config.txt文件中的设置将被清除**。
> - 重启parsec后，我们可以再次打开`config.json`检查配置项，确保我们在`config.txt`的配置已生效。
> 
> 本文以下内容介绍一些经验上需要做的配置，默认在`config.txt`进行配置，保存文件后重启parsec。

# 配置应用级别代理

某些组织可能会选择将 Parsec 应用程序配置为在其环境中使用特定代理，而不是系统级代理。此功能适用于 Windows、MacOS 和 Linux 计算机，并且需要 Parsec 应用程序版本 150-82 或更高版本。配置后，此代理将用于对 Parsec 的 HTTP 和 WebSocket API 发出的所有请求。

这个设置对于**大陆的网络环境**来说是**必要**的，所以必须进行配置。

首先介绍相关配置项：

- `app_proxy`：启用应用级代理。 0为禁用，1为启用
- `app_proxy_address`：代理的主机名或 IP 地址。直接填 127.0.0.1
- `app_proxy_port`：代理端口，猫咪默认为7897，其他魔法自己看软件内所使用的端口。

配置的步骤如下：

- 打开`config.txt`，输入以下内容（例子）：

```
app_proxy = 1  
app_proxy_address = 172.0.0.1  
app_proxy_port = 7897
```

- 保存txt文件，然后重启parsec
- 打开`config.json`就可以确认配置是否迁移并生效。
