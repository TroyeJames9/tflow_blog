# 皮肤招募系统说明

## 关于皮肤招募新机制

- 新增了皮肤招募界面和动画。使用皮肤招募券有机会获得伊莎贝尔皮肤。
- 您可以在8次招募内获得所有奖励，包括皮肤。奖励只能领取一次。
- 活动期间，可以通过任务和活动通行证**免费获得总共 2 张皮肤招募券。**
- **新增货币：S点数，美元计价前提下， 160S点数=\$6，490S点数=\$14，1000S点数=\$30**
- **额外招募券可以每张 80 S 点数购买。**
- **未使用的皮肤招募券将在活动结束时过期。**

# 活动赛事

一周七天，每天都可以挑战不同的队伍！赛事比赛分阶段进行，并设有三个难度级别：普通、困难和非常困难。

- 每日奖励包括 25 个活动币和 2,000 个随机的专精点数（两种）。
- 每日奖励补充后可获得 25 个活动币。
- 每天可以额外购买一张入场券，价格为 50 蓝焰。
- 重要的活动任务：**活动球员招募50次招募后可获得1个皮肤招募券**

# 全新球员专属专精

- **伊莎贝尔 / 最后手段：** 进行鱼跃时积攒格挡槽。每回合可发动一次。
- **伊莎贝尔 / 格挡稳定：** 保持格挡槽在 30% 或更高，但限制其最大充能为 70%。
- **塔尼亚/超级齿轮：** 最大二传等级翻倍。（？）
- **塔尼亚/快速链接：** 当塔尼亚第一次触球时，快速传球的效果也会作用于第二次触球。但是，快速传球的威力加成会降低。
- **克莱德 / 替补上场：** 即使 克莱德 注册为替补，猫咪也会出现在球场上。
- **克莱德/纳维的漫步：** 增加触发对手“分心”状态的几率。但是，它会将你方队伍的状态从“专注”变为“兴奋”。
- 每次得分后，塔尼亚都可以利用她的特性来提升二传等级。随着等级提升，传出的球的重力和高度也会增加。
- 当猫咪在场上时，克莱德获得了一个新的特性，可以增加全队的专注持续时间和所有队友的防御力。
- **志勋**：“奇迹二传”现在即使在比分持平或你方领先的情况下，也能使球的威力提升10%。当你方落后时，加成幅度会根据分差增加，最高可达35%。
- **志勋**：现在传球范围在三米线内。
- **志勋**：其返还的突破数将在您登录时发送到您的邮箱。（？）

## 剧情模式章节重组

剧情模式章节已按如下方式重组。

| 分类          | 说明              |
| ----------- | --------------- |
| 第1季、第2季、第3季 | 主线故事            |
| 支线故事        | 延续主线故事的活动剧情     |
| 主题故事        | 独立于本篇故事之外的活动剧情  |
| 背后故事        | 探索每个角色个人故事的支线故事 |

原先位于支线故事中的角色专属支线故事，现归类为背后故事。

活动剧情现在分为支线故事（主线故事的一部分）和主题故事（与主线故事分离）。

---

大家好。

我是 Ohjun Kwon，是《The Spike Cross》的开发者之一，也是 SUNCYAN 的 CEO。

我一直在阅读大家对于“人造人之夜”更新中皮肤获取和购买方式变更的反馈。你们的留言让我思考了很多，尤其是这些改动所带来的失望和沮丧。

你们中的许多人曾期待这次更新，很抱歉我们让你们失望了。有些人花了很长时间为自己最喜欢的选手攒钱买皮肤。我们本应更仔细地考虑这项改动对你们意味着什么，并在更新前作出解释。

我想尽快回应。但我们也需要思考，仓促决定是否会制造更多问题，尤其是对那些已经完成购买的玩家。阅读世界各地玩家的反馈并考虑如何回应需要时间。很抱歉让你们久等了。

**我们考虑皮肤系统的改动已经很久了**。

随着我们为《The Spike Cross》加入更多选手和皮肤，旧复刻系统的局限性越来越难以绕过。每次复刻时，都有更多玩家已经将当期限定选手达到最高突破等级。有些人不得不招募自己已不再需要的选手，只是为了获得一款皮肤。另一些人则已经同时拥有该选手和皮肤，导致他们几乎没有理由参与活动。

将皮肤活动与选手复刻绑定，也限制了我们安排复刻的自由度，包括新选手多久后可以回归。改进回归玩家机制与制作新皮肤分散了我们团队的时间和精力。回头看，我认为这两件事我们都没有做得足够好。

**我也想坦诚说明我们在持续开发游戏过程中面临的一些挑战。**

**我们一直希望做一款让大家不会感到有消费压力、只要经常游玩就能收集自己想要内容的游戏。但随着开发和运营成本增长，维持这种做法变得越来越困难。**

**我们知道我们的皮肤质量仍有提升空间。我们正在继续投入更多时间和资金，用于皮肤插画、游戏内模型和动画。**

由于全球有如此多玩家在玩，即使是很小的新增内容也可能意味着更高的运营成本。为了持续添加功能，包括让玩家彼此互动的社交功能，我们需要一种可靠的方式来支撑这些成本。

**由于可游玩角色会直接影响玩法，我们希望你们尽可能通过游玩来获得他们。我们决定通过让付费购买成为获取皮肤的主要方式，来支持这一方向。**（即用皮肤付费的商业模式去反哺球员本体的f2p）

我们事先没有详细解释这些顾虑，是因为我们不想让公司的困难变成你们需要担心的事情。我们认为，处理好这些问题并带来更好的更新是我们的职责。我们也担心，谈论这些困难听起来会像是在找借口。

但这些改动直接影响了你们如何游玩以及选择购买什么。我们本应在作出改动前解释原因并请求你们的理解。长时间在内部讨论这些改动，并不意味着我们已经给了你们所需的解释。我们没有认识到这一点。

通过这次调查，我们想听听最让你们失望的是什么，以及你们希望我们改变什么。请诚实地告诉我们你们的想法。

**我也不想给你们无法兑现的期待。即使我们让皮肤更容易获得，或增加通过游玩获得奖励的方式，不花钱获得皮肤可能仍会比过去花费更多时间和精力。为了继续制作新内容并长期支持游戏，我们也需要确保在游戏上花钱是值得的。**

我们理解，当这改变了你们长期享受的东西时，这可能难以接受。我们会继续寻找方法，确保游玩游戏和期待下一次更新仍然是值得的体验。

**如果我们在本次活动期间提供更好的 S 点产品折扣或更低的礼包价格，我们计划向在改动前购买了受影响产品的玩家提供补偿。该补偿将反映更新后的购买条款。当我们宣布任何此类改动时，也会说明谁有资格、补偿如何计算以及何时发放。**

我们会阅读调查的每一份回复，并尽可能根据你们的反馈采取行动。在审阅你们的回复后，我们会分享我们可以改变的内容以及正在准备的改进。

再次为这次更新让你们失望，以及花了这么长时间解释我们的决定而道歉。我知道这条信息不会回答所有问题，也不会化解你们所有的沮丧。但即使已经晚了，我觉得我欠你们一个诚实的解释。

感谢你们关心《The Spike Cross》，也感谢你们即使失望仍花时间分享想法。我们会认真倾听，并努力带来更好的更新。

Ohjun Kwon
