# 四个新球员

通过此更新， **Lucas卢卡斯、Zero零、Hari哈里 和 Crow克劳** 将可以作为可招募和可玩的角色。

![|692](Kingmaker-20250809101233329.webp)

所有四个新角色均可在**活动期间通过 Kingmaker 活动招募**进行招募。

- 本次活动招募，可以使用活动奖励获得的**王者币（Kingmaker Coins）** 来招募玩家。
- 每次招募需要花费 **40 个王者币** 。
- 活动招募中， **共有 5%的概率**获得 **S 级及以上**玩家，S 级及以上详细概率如下。
- 您还将**在每次招募中获得 1 个活动招募点数** ，点数可用于新球员以及部分旧球员的**保底兑换点数**。

- S级**Zero零 (Se)**: 0.8%，100 活动招募点数

- S-级**Crow克劳 (MB)**: 1.1%，80 个活动招募点数

# Kingmaker活动详情

![](Kingmaker-20250809102643164.webp)

## 活动比赛规则

- 比赛将根据指定的难度等级每天举行： **EASY简单 / NORMAL普通 / HARD困难** 。
- 所有比赛均遵循 **12 分规则** 。
- 每个难度级别包含 **2 个阶段** 。
- 每场比赛前，都会出现**技能卡选择**屏幕。
- 每个阶段**通过轮盘选择两张卡牌** ，总共**四张竞技场场卡牌** 。
- 在**第 2 阶段**中，所有**四张选定的卡牌**都将在比赛中使用。
- 轮盘中显示的卡片是从固定的活动专用卡片列表中随机选择的，无论您是否拥有它们。
- 比赛开始时，将随机选择**四个可能的阶段之一** 。
- 在困难**难度**下，将应用**雪地反接规则** 。

## 活动比赛奖励

您可以通过完成每个难度级别的阶段来赚取王者币（Kingmaker Coins）。

- **简单：** 92 个 王者币（Kingmaker Coins）
- **普通：** 93 个 王者币（Kingmaker Coins）
- **困难：** 95 个 王者币（Kingmaker Coins）

> [!warning] 注意
> 王者币在活动结束后将会过期，因此请务必在活动结束前使用。

## 奖励重置券

奖励重置券可用于重置当日的活动比赛，可再次参加活动比赛。

- 您可以在 活动商店 购买**奖励重置券** 。
- **每天可购买一次，** 费用为 **100个排球** 。
- 此物品仅可**在您领取每日奖励后**使用。

# 其他优化和改进

- 更多的预设组合：黄金[段位](游戏/The%20Spike%20Cross/游戏百科/资源获取方式/段位.md)拥有3个预设，钻石等级拥有4个预设

> [!INFO] 关于“提高安全稳定性”的科普
> SUNCYAN在最新更新中已切换到一种新的方法，即使用编译器以机器码编译游戏，而不是使用旧的解释代码。开发人员不仅通过反作弊功能，而且在游戏的客户端部分，对游戏的保护也进行了数千倍的增强。
> 
> 因此，各种破解方式都需要一定时间去从机器码的层次去破解
