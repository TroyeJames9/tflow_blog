# 注册APPLE ID

**<span style="color: #ff7575">任何设备均可以注册APPLE ID并使用其登录游戏。</span>**

游戏可以使用google账号或者apple ID 登陆。但由于谷歌账号有**注册条件严苛+不能送中+容易风控**这三大问题，所以本教程强烈建议直接注册一个大陆 apple id 来登陆游戏即可，无需使用google账号。

注册 apple id可以使用的邮箱有：QQ邮箱、163邮箱、 outlook邮箱。

**一个邮箱只能注册一个apple id。一个手机号可以注册多个apple id。**

[点击本链接](https://account.apple.com/account) 进入苹果中国官网来注册全新的大陆 Apple ID

# 注册谷歌账号

> [!tip] 需要代注册账号？
> 如嫌麻烦、没电脑或无法注册，强烈建议[点击我联系tflow](app://obsidian.md/%E6%9D%82%E8%AE%B0/%E5%A6%82%E4%BD%95%E8%81%94%E7%B3%BBtflow%EF%BC%9F.md)代注册谷歌账号（20元，包售后），太多人在其他途径买到黑号被风控而丢失了，尤其不推荐去 **<span style="color: #ff7575">ourplay</span>** 买，又贵又容易丢失

本部分参考了[注册教程1](https://shuziyimin.net/account/google)和[接码教程2](https://shuziyimin.net/skill/sms-activate)，特别鸣谢。

如果你是苹果用户，打算使用APPLE登录游戏，则本注册教程**非必做项**。

**电脑**打开浏览器，为避免国内+86手机号可能遇到被封掉手机号验证资格的情况，**强制要求在电脑端使用Chrome浏览器来注册，否则后果自负（不提供代注册服务）**。

如果你人不在大陆，手机也可以注册。

**电脑**打开魔法，并进行以下设置：

- **使用无痕模式**：打开 Chrome 浏览器的`无痕模式`，避免旧有 cookie 的干扰。
- **切换环境语言**：将设备或浏览器的语言设置为 `English`，地区设置为美国或其他国家。
- 地址栏输入[https://accounts.google.com/](https://accounts.google.com/) 进入账号注册页
- 开始创建账户，点击Create account（创建账户）--For my personal use（供我个人使用）
- 填写个人信息，依次填写后点击Next：
- **出生月、日、年**（随便选个已成年日期）
- 验证手机号时，选择+86中国地区

> [!TIP] 提示
> - **注册成功后请注意**：在最初的一周内，尽量使用同一个网络节点登录和使用 Google 服务，避免因 IP 大幅跳动而触发二次手机验证。
> - 务必要牢记账号和密码，强烈建议加上**两步验证（谷歌验证器）、备用码、辅助邮箱、辅助电话号**等安全措施，否则一旦丢失、被封号或风控，很难找回账号
> - **如果手上可用的电话号注册均失败**，可选择：
> 	- [点击我联系tflow](杂记/如何联系tflow？.md)代注册谷歌账号
> 	- 认真阅读[谷歌账号注册](国外/谷歌账号注册.md)并尝试（**<span style="color: #ff7575">接码有很大的账号丢失风险，只推荐在手机的gmail app注册</span>**）
