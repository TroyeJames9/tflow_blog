# ■ 活动时间

- **持续时间：** 4月28日 – 5月27日（共30天）

# ■ 如何参与活动

## 幻影出现！

在活动期间，当您进行锦标赛比赛时，有 **16%** 的几率遇到名为“幻影”的特殊队伍。

## 幻影入侵限制

- 您每天最多可以遇到幻影队伍 **3次**。
- 如果您输给幻影队伍，当天的次数 **不会** 被消耗。
- 您可以在主屏幕的活动横幅中查看剩余的入侵次数。

## 比赛选择

![|400](Afile/20260428八周年庆-20260427162607667.webp)

当您遇到幻影队伍时，您将看到两个选项：

- **接受比赛：** 开始与幻影的特殊活动比赛。
- **拒绝比赛：** 继续您正常的锦标赛比赛。  
    _(如果您拒绝，当天的遭遇次数限制将不会被消耗。)_

# ■ 错误修复

- **剧情模式：第4章（超级巨星挑战）** — 修复了当珍妮的“烧掉船只”特性激活时，聊天中出现佯攻提示的问题。
- **故事模式：第4章（超级巨星挑战）** — 修复了观众增加/减少箭头显示不正确的问题。
- 修复了徐莎拉 (WS)的“突风”天赋未正确应用额外跳跃力的问题。
- 修复了徐莎拉 (WS)的“凛冽寒风”天赋在30 FPS下蓄满力时未正确出界的问题。
- 修复了部分球员（如昊天, 徐莎拉(WS)）在扣球后空中移动过快的问题。
- 修复了昊天在地面时状态颜色未更新的问题。
- **练习赛：** 修复了在平衡模式下，劳尔和徐莎拉(WS)的挥臂延迟比其他球员短的问题。
- 修复了二传手尚未传出球时，主攻截球所扣出的球会出现异常缓慢下落的情况。
- **跳飘球：** 修复了一直按住扣球键导致击球点过低的问题。
- 修复了婚纱伊莎贝尔的部位索引显示不正确的问题。

# ■ 优化

- 提高了进入球员管理界面时的加载速度。

# ■ 改进

- 在比赛中增加了回合进行时的观众欢呼声。
- 在设置菜单中增加了不同类型欢呼声的音量控制。
- 改进了隐私政策弹窗的布局和内容。

# ■ 平衡性调整

- 在锦标赛和竞技场比赛中，**<span style="color: #ff7575">左侧队伍现在将始终先发球。</span>**
- **<span style="color: #ff7575">（尤其练习赛）没有西川“双重击”天赋的球员不再能进行第二次挥臂。</span>**
- **<span style="color: #ff7575">在练习赛中增加了一个选项：当启用“双重击”时，普通球员也可以进行双重扣球。</span>**
- **<span style="color: #ff7575">降低了球网高度，并放宽了“球触网后过网”的判定条件。</span>**
- **AI改进（仅限队友）：** 除非是快攻，否则副攻MB将不再拦截暴露性传球（Open sets）。
- **发球调整：**
    - 当您发球时，对手现在有稍多的时间准备防守，反应会有轻微延迟。
    - 如果受控球员在队伍中，则不适用此规则。
    - 当您发球时，“无触球发球得分”的几率增加。
    - 然而，发球得分越多，对手的反应时间将逐渐再次缩短。
- **雪地战：** 为物品升级属性增加了上限。

# ■ 锋泽天赋重做

**1. 现有天赋变更：守护之泉 → 神盾**

- 防御力最低的队友将成为“神盾”的目标。
- **防御力 +30，防御范围 +30%** (持续10秒 / 冷却15秒)
- 接住一次扣球后效果移除。

**神盾的突破效率**

- **+0 突破:** 防御 +30, 防御范围 +30% (持续10秒 / 冷却15秒)
- **+1 突破:** 防御 +35, 防御范围 +30% (持续10秒 / 冷却15秒)
- **+2 突破:** 防御 +35, 防御范围 +30% (持续10秒 / 冷却15秒)
- **+3 突破:** 防御 +40, 防御范围 +30% (持续10秒 / 冷却13秒)
- **+4 突破:** 防御 +40, 防御范围 +30% (持续10秒 / 冷却13秒)
- **+5 突破:** 防御 +50, 防御范围 +40% (持续10秒 / 冷却11秒)

**2. 新增特性：惩戒**

- 如果处于“神盾状态”的球员成功接住了吊球，他们将切换为“惩戒状态”。
