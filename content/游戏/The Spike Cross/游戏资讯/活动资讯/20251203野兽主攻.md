# 新模式：阵容战

我们很高兴推出一个新的活动模式：阵容战！

![](Afile/20251203野兽主攻-20251129083937271.webp)

每周，玩家可以**选择一个阵营**并参与阵营战以获得贡献点数（**Contribution Points**）。

累计的贡献点数会应用到你选择的阵容上，总积分最高的阵容获胜。

阵容总贡献点数将在每周开始后3天公布。

失败的阵营将获得**弱势加成**，提升下一轮的总贡献点数。

- 每周获胜阵容奖励：280野兽币，150排球，5张普通球员招募券
- 每周失败阵容奖励：280野兽币，150排球，2张普通球员招募券

![](Afile/20251203野兽主攻-20251129084201804.webp)

- 阵容战可在**简单**或**困难**模式中游玩。
- **阵容战**对**黄金段位及以上**玩家开放。
- 比赛前，选择卡牌来**提升球员的属性**。
- 所选卡牌在单轮阵容战回合**期间保持有效。
	- 你每天可以选**两张牌**。
	- **卡牌组合**时可升级，最高可达**5级**。
	- 贡献点数数是根据比赛胜利点数计算的。
- **贡献点数系统与活动额外入场券**
	- 每达到**10点贡献点数**即可获得**50野兽币**。
	- 你可以在活动商店购买**活动额外入场券**。价格100排球，每天只可买一次
	- 这些门票可在**达到每日贡献点数目标（10点数）**后使用。
	- 所以每天最多获得100+280/7 = 140野兽币

# 新的球员熟练度系统

为你的球员引入了新的**熟练度系统**。**熟练度是你所拥有每个球员的荣誉象征**。

当球员在比赛中得1分时，3名贡献分数的**球员**将获得 **+1的熟练度** 。

- `熟练度来源`：可以在**锦标赛、竞技场和雪地战**中获得。等级提升所需熟练度**会因熟练度等级**而有所不同。
- `熟练度等级`：**新秀→老将→精英→传说→冠军** 。
- `各等级晋升条件`
	- 新秀：无条件，无奖励，初始等级。
	- 老将：500锦标赛熟练度，200竞技场熟练度，50雪地战熟练度。晋升奖励为 该球员该段位得分动画、20万球芒币，10万经验值，5个普通球员招募券
	- 精英：1500锦标赛熟练度，500竞技场熟练度，150雪地战熟练度。晋升奖励为该球员该段位得分动画、30万球芒币，20万经验值，10个普通球员招募券
	- 传说：4000锦标赛熟练度，1200竞技场熟练度，800雪地战熟练度。晋升奖励该球员该段位得分动画、40万球芒币，40万经验值，15个普通球员招募券
	- 冠军：敬请期待

# 新的球员特性与更新

**以下角色获得了新的特性：**

- `罗伯特`：**团队护甲**，提升所有队友的 **防守范围和** 接发时的防御属性。
- `山寺`：**增援**，当对手连续发球得分时，提升**球队防守**。
- `锋泽`：**稳如泰山**，每10次触球恢复**20点队伍生命值（耐力）** 。
- `莉西亚 / 维奥拉`：**卓越专注**，每当对手在比赛中发球得分时，永久提升**队伍生命值（耐力）10**点。
- `莉西亚`：**阳光**，她第一次通过换人进入场地时，会解除所有队友的状态，并让他们进入专注状态。 
- `塔尼娅`：**高速二传（仅限自身）**，在**拉锯战**中减少30%速度损失。
- `金熙成 / 克劳`：**快速恢复**，得分或失球后恢复的**HP（耐力**）增加。
- `莎拉`：**高速二传**，在**拉锯战**中减少30%速度损失。

**以下现有特征得到改进：**

- `克莱德`：技能触发时附加效果为 **+15点队伍生命值（耐力）。** 
- `素熙`：使用技能时恢复15点队伍的HP（耐力）。 **史诗级加强**
- `维奥拉`：新增游戏内技能开关图标。可以操控她是否传底线了
- `芷柔`：向日葵技能新增游戏内开关图标。
- `莉西亚`：使接到天空球发球的对手在该回合中进入沮丧状态。
